## 建议

1. 为头像提供有意义的替代文本，并在图片不可用时显示名称首字母或稳定占位内容。
2. 图片加载失败后保留布局尺寸，避免列表行因资源错误而跳动。
3. 将回退视觉和可访问名称保持一致，让图片与文本用户得到同样的身份线索。
4. 为回退元素保留固定尺寸和可读名称，并在图片状态切换时避免列表内容重新排列。

## 常见反模式

- 头像请求失败后留下空白区域或损坏图片图标。
- 用随机颜色或随机字母作为唯一身份线索。
- 没有替代文本，且回退元素无法被辅助技术识别。
