Lorelum Skill 指导 Agent 判断何时需要工程指引、如何描述任务和时刻，以及为什么应用前要读取 Practice 全文。宿主负责发现 Skill，`lore` CLI 负责检索知识。

请先完成[快速开始](./quickstart)。Agent 执行命令的环境中需要有可用的 CLI，并已安装至少一个 Pack。

## 选择接入方式

| Agent                  | 接入方式                                                         |
| ---------------------- | ---------------------------------------------------------------- |
| Codex                  | [官方 Plugin](./codex)，包含 Skill 和注入已安装 Pack 目录的 Hook |
| Claude Code            | 项目级或个人级 Skill                                             |
| Cursor                 | 项目级 Skill                                                     |
| 其他能执行命令的 Agent | 宿主支持的 Skill 或项目指令                                      |

## Codex

安装 [Codex Plugin](./codex)。它提供 Skill，并在受支持的会话事件中让 Agent 发现已安装 Pack 及其可直接读取的当前 `packRoot`。Catalog 不注入 Practice 正文或资源内容。Plugin 使用现有 CLI 和 Store，二者需要单独安装和准备。

## Claude Code

将 [Lorelum Skill](https://github.com/lorelum/lorelum/blob/main/skills/lorelum/SKILL.md) 下载到项目的 Skill 目录：

```sh
mkdir -p .claude/skills/lorelum
curl -fsSL https://raw.githubusercontent.com/lorelum/lorelum/main/skills/lorelum/SKILL.md \
  -o .claude/skills/lorelum/SKILL.md
```

个人级安装使用 `~/.claude/skills/lorelum/SKILL.md`。Skill 的发现与调用规则见宿主的 [Skills 文档](https://code.claude.com/docs/en/skills)。

## Cursor

将同一份 Skill 安装到项目中：

```sh
mkdir -p .cursor/skills/lorelum
curl -fsSL https://raw.githubusercontent.com/lorelum/lorelum/main/skills/lorelum/SKILL.md \
  -o .cursor/skills/lorelum/SKILL.md
```

宿主行为见 [Cursor Skills 文档](https://cursor.com/docs/skills)。

## 其他 Agent

能够执行命令的 Agent 可以调用同一套 CLI。按宿主支持的方式安装 Skill；若宿主使用项目指令，则将 Skill 的检索指导放入对应指令文件。

核心行为是：在 `lore query` 中描述任务和当前判断，用 `lore get` 读取相关结果，再按适用条件应用指导。取回的 Practice 包含 `resource:` link 时，已安装 Skill 会说明如何用返回的可变 current `packRoot` 解析它、按需读取 reference、复制 asset 后编辑，以及只在当前任务授权下显式运行 script。完整执行约定见 [Agent 使用说明](./agents)。

## 验证接入

启动新任务并要求：

```text
请用 Lorelum 为当前改动查找工程指导。
完整读取一条相关 Practice，说明它如何影响实现或验证决策。
```

检查 Agent 的实际命令：它应检索结果，并读取准备应用的 Practice 全文。若命令不可用，在 Agent 环境中运行 `lore --version`，检查 `PATH`。若查询正在准备或失败，按[故障排查](./troubleshooting)处理。

## 更新 Skill

文件式安装需要先查看 Skill 更新，再将新文件下载到同一位置。Codex 用户更新 Plugin 即可。更新 Skill 不会同时更新 CLI 或已安装 Pack。
